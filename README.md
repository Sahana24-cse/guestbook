# Guestbook Application

## Project Description
A simple Guestbook application developed to understand cloud-native application deployment and DevOps workflows.

## Features
- Guestbook application
- Version-based application deployment
- GitHub repository management
- CI/CD workflow configuration
- Kubernetes and OpenShift deployment concepts

## Technologies
- HTML
- GitHub
- Docker
- Kubernetes
- OpenShift
- Tekton

## Application Versions
- Version 1: Guestbook v1
- Version 2: Guestbook v2
